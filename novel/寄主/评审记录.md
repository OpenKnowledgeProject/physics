# 《寄主》· 评审记录

制作流程与逐轮评审问题清单。评审与写作分离：每轮评审是一次独立遍读，只带一个镜头。

## 阶段门

| 门 | 通过条件 |
|---|---|
| G0 立项 | 骨架齐：README / 大纲 / 章节设计 / 正文目录 |
| G1 大纲定稿 | 六个镜头各过一轮，无开放 P0/P1 |
| G2 全稿初稿 | 22 个文件齐，章节状态表全"初稿" |
| G3 成稿 | 全稿评审无开放 P0/P1 → 打 tag `寄主-v1.0` |

每阶段评审上限 5 轮；第 5 轮仍有 P0 → 停笔，与作者本人定方向。

## 问题分级（按本书）

**P0 致命**：违反七条规则或"无它"纪律（出现 AI 对白 / 模型名 / 拟人化反派）；情节无法由已立规则推出；信息差穿帮；中点 / 低谷 / 高潮失效（引擎不推情节）；人物弧光断裂。

**P1 严重**：钩缺失或连续同型；双线失衡、交汇章处理错；抽象概念直接宣讲（无文书形态）；人物声音不分；时间线 / 数字矛盾；主题句直说；规则先用后立。

**P2 润色**：命名、意象密度、古典回声浓度、句级。

## 评审镜头（每轮一个，独立遍读）

1. **设定纪律**：情节是否全部由规则推出；有无规则先用后立；"无它"红线。
2. **结构与钩子**：节奏、钩型轮换、中点/低谷/高潮落点、双线交汇处理。
3. **信息差与时间线**：对照信息差矩阵逐章核对；纪年与数字。
4. **人物与声音**：弧光诚实度；对话能否靠措辞习惯区分人物；蟋蟀式发言是否全部"理性成立"。
5. **主题与留白**：主题是否经由场景而非宣讲；留白清单是否被无意填掉。
6. **文体规范**：对照 shared/写作规范.md 与大纲"写作注意事项"。

## 评审执行

- 每轮：一个镜头 → 问题记入下表（编号 R<轮>-<序号>）→ 修复 → 状态改"已修"或"不修"（注明理由）。
- 陌生读者原则：评审者不带写作记忆读稿。可用新会话 / 子代理做评审遍；作者的修改意见随时插入表中，级别由作者定。
- 修复一律改原文，不留"待改"批注进正文。
