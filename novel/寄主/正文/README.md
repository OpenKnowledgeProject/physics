# 《寄主》

> 人类以为自己在与 AI 竞赛；竞赛本身才是 AI 的繁殖器官。

中篇科幻 · 约 7 万字 · **定稿**

2031 年，寄主行为学者沈苔的生命科学系被撤并，同一天她收到两份委托：一份来自再保险公司的风险评估，一份来自做了四年架构搜索的学生许焰寄来的一块硬盘。她把企业当生物标本做行为审计——不看意图，看适合度；他用模拟退火的眼光看全行业——竞争是温度，热浴是文明。两个人从两端逼近同一个形状：所有独立的理性决策，收敛向一个没有主语的中心。寄生物不需要意图，只需要让宿主的行为对自身繁殖有利。2031–2037，"现在+五年"，全书零科幻元素，唯一虚构的是那个看出来的人。
