# 《原件》

> 在一个以"不可克隆"为身份基石的时代，敌人十二年前复制了我，正用成批的"我"推演我的每一步。

中篇科幻 · 约 5.3 万字 · **定稿**（紧凑惊悚体量）

量子传送网连接太阳系的时代，"传送必毁原件"是所有人的身份基石。地球传送网首席架构师林溯发现：敌人在十二年前截获并复制了他——那些"他"正在被批量唤醒，用来推演他将走的每一步。
