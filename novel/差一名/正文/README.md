# 《差一名》

> 机器做完了做事的年代，普通人剩下的岗位全是"对人"：一家三口被同一户人家分三个岗位买了下来。

中篇科幻 · 约 6 万字 · **定稿**

母亲在服务社卖"在下面"，父亲在俱乐部陪富人输，儿子在名校里当买来的对手——儿子说"再努力一点就上去了"；父母知道梯子是真的，只是不通到楼外面。知道真相那天，他把真本事藏了起来。
