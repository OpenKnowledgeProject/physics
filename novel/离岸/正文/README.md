# 《离岸》

> 时租航线上富人把死亡取消了，留下的人给活人守了八十年陵。

中篇科幻 · 约 9 万字 · **定稿**

近光速"时租"航线开通的年代，富人买下了新的不平等：登上不同 γ 值的飞船，按自己的钟生活——地球的钟在窗外疯转。遗产永不分配，资本跨世纪复利。陆念十七岁那年被全家送上 γ=20 的飞船，去等一个能治好她的年代；八十一个地球年后她依然二十五岁，家却被信托保存成了纪念馆，而接待她的引导师，是哥哥一支的第四代看照人。
