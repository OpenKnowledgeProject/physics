# 审读规范（跨作品）

成稿后（初稿完成 + 扩写达标后）执行。原则：**分维度跑，一轮只看一类问题**；发现先分级再动手。

## 锚点表（审读前置工件）

每本书在 `章节设计.md` 或 `设定/` 里维护一份锚点表，审读以此为准绳，不靠记忆：

- 时间锚点：关键纪年相互差值（如"距登船 X 年"换算表）、人物生卒年、生理龄/历龄链
- 人物锚点：亲属链与称谓对照、代际关系
- 规则锚点：世界观硬规则的换算式与边界（γ 值、邮包窗口、章程条款）
- 物件锚点：关键意象/道具的来历与去向（哪里埋、哪里收）

写作中持续更新；审读逐条对照。

## 审读管线

**自查三轮**（作者或 AI 主审，分维度独立跑）：

| 轮 | 维度 | 对照工件 |
|---|---|---|
| R1 | 一致性：时间线/亲属/物理规则/邮包文书逻辑 | 锚点表 |
| R2 | 文风 | `shared/写作规范.md` + 本书写作注意事项 |
| R3 | 结构：钩子/双线配比/意象回收 | 章节设计蓝图 |

**独立复审一轮**（强烈建议，本次已验证检出率高于自查）：

- 派三个只读 subagent 分维度独立审读，要求通读全稿后出分级清单
- 主审逐条评估：**采纳 → 原地修复**；**驳回 → 写明理由登记**。预期驳回率 10–20%（误读与风格偏好），不可照单全收也不可全驳
- 重点关注自查盲区：设定算术（纪年上限、换算链）、多轮插入的接缝、只埋不收的意象

## 分级与裁决

- **P0**：硬伤/物理不可能/断稿级 → 必修
- **P1**：确凿矛盾（年数、称谓、规则引用、接缝重复）→ 原地修复
- **P2**：可辩的含糊/风格偏好 → 逐条登记"改/不改"，不改须一句话理由
- 风格化选择（句式密度、意象单点使用、刻意留白）默认判"不改"，防把声音当 bug 削掉

## 流程纪律

- 每轮输出发现清单 → 原地修复 → 批次提交（`书名: 审读维度`）→ 审读记录写入 `章节设计.md` 状态表末尾
- 修复批次的字数变动后复测阈值
- **停止条件**：一轮审读 P0/P1 为零
- 结稿动作：README 状态卡改定稿 → `git tag <书名>-v1.0`
