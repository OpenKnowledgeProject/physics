# 生产流程（跨作品）

点子到定稿的流水线。评审与写作分离：每轮评审是独立遍读，subagent 当陌生读者。
单书执行记录（阶段门状态 + 逐轮问题清单）记于 `novel/<书名>/评审记录.md`。

## 流水线

```
ideas.md 点子行 → G0 立项 → G1 大纲定稿 → G2 章节设计定稿
  → G3 全稿初稿 → G4 全稿审读 → 扩写达标 → 精炼 → G5 定稿(tag)
```

## 阶段门

| 门 | 进入条件 | 通过条件 |
|---|---|---|
| G0 立项 | 点子成熟 | 骨架齐：README／大纲／章节设计／正文；ideas.md 立项行 |
| G1 大纲 | 大纲初稿 | 六镜头评审无开放 P0/P1 |
| G2 章节设计 | 大纲定稿 | 钩型地图、信息差落章、字数预算过评审 |
| G3 初稿 | 章节设计定稿 | 全部章节成稿，状态表全"初稿" |
| G4 审读 | 全稿初稿齐 | 一致性／文风／结构三轮镜头无开放 P0/P1 |
| 扩写 | G4 后字数盘点 | 各章达分级字数下限（常规/关键章分档） |
| 精炼 | 扩写达标 | P2 抛光轮无新增 P1+ |
| G5 定稿 | 作者认可 | 打 tag `<书名>-v1.0`，README 状态行更新 |

## 评审通则

- **陌生读者原则**：评审用只读 subagent，不带写作记忆；每个评审遍只带**一个镜头**。
- **并行分派**：同轮各镜头并行派出，合并记为一轮，编号 `R<轮>-<序号>`。
- **分级**：P0 致命（阻塞，不修不过门）／P1 严重（必修）／P2 润色（登记可延）。
- **轮次上限**：每阶段 5 轮；第 5 轮仍有 P0 → 停笔，与作者定方向。
- **修复纪律**：一律改原文，不留"待改"批注进正文；已修／不修（注明理由）逐条销号。
- **作者优先**：作者意见随时插入问题表，级别由作者定。

## 各阶段镜头

### G1 大纲评审（六镜头）

1. **设定纪律**：情节能否全部由已立规则推出；有无先用后立；本书红线。
2. **结构与钩子**：节奏、钩型轮换、中点／低谷／高潮落点、多线交汇（若有）。
3. **信息差与时间线**：对照信息差矩阵逐章核对首现/揭晓/回收；纪年数字链。
4. **人物与声音**：弧光诚实度；措辞规格能否区分人物；配角参照系。
5. **主题与留白**：主题由场景承载而非宣讲；刻意留白清单不被无意填掉。
6. **文体规范**：对照 `shared/写作规范.md` 与大纲"写作注意事项"；字数预算自洽。

### G2 章节设计评审（抽镜头）

- 结构与钩子：全钩型地图无相邻同型。
- 信息差落章：矩阵每条信息有首现章／揭晓章／回收章。
- 字数预算：逐章合计与部目标一致。

### G3 初稿（不设逐章评审门）

- 写作规范："初稿优先写完，不回头改前文"；修订意见记入章节状态表备注。
- 每写完一章：更新状态表（状态＋字数）与 README 进度行，会话末提交。

### G4 全稿审读（三轮大镜头）

1. **一致性**：时间线／年数链／称谓／信息差回收／规则无破。
2. **文风**：写作规范＋声音规格＋意象密度＋宣讲检测。
3. **结构**：节奏、钩子、中点高潮落地、收束质地。

### 扩写

- 低于下限章扩写；扩写章回炉一致性抽评（新段落最易断链）。

### 精炼

- 句级／命名／意象密度抛光，只动 P2；发现 P1+ 回 G4 流程。

## subagent 分派模板

每个评审遍派一个只读 subagent，prompt 必含：

1. 身份声明：陌生评审，只读，不改任何文件。
2. 必读文件绝对路径清单。
3. 唯一镜头＋逐条检查清单。
4. 本书红线（从评审记录"问题分级"复制）。
5. 输出格式：发现表（位置／级别／问题／建议修法）；无发现也要明说。
